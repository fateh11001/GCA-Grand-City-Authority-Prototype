Open https://nodejs.org/en/download?utm_source=chatgpt.com
Select the latest LTS release.
Choose macOS.
Download the x64 (.pkg) installer.
Install it normally.

Then:
node -v
npm -v

You should see two version numbers, something similar to:
v22.x.x
10.x.x

Run:
cd ~/Documents/"GCA - Grand City Authority Prototype"
npm init -y
npm install three
npm install -D vite
mkdir -p public/assets src/core src/world src/player src/vehicles src/npcs src/missions src/audio src/ui src/utils

Then:

rmdir src/vehicles src/npcs src/missions src/audio
mkdir -p public/assets/models public/assets/textures
rm -rf public src
mkdir -p public/assets/models public/assets/textures src/core src/world src/player src/ui

Then:
npm pkg set scripts.dev="vite" scripts.build="vite build" scripts.preview="vite preview"

Open package.json in VS Code.

You should see a section similar to:
"scripts": {
  "dev": "vite",
  "build": "vite build",
  "preview": "vite preview"
}

STEP 4 — Change the JavaScript module type
1. Keep package.json open in VS Code.
2. Find this line:
   "type": "commonjs",
3. Change it to:
   "type": "module",
4. Press Command + S to save.
